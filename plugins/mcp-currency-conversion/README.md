# MCP Currency Conversion

Real-time currency exchange rates and conversion via a free public server (no API key).

## Installation

```bash
/plugin install mcp-currency-conversion@wookstar-claude-plugins
```

Connects straight to the server's streamable HTTP endpoint - no Node or `mcp-remote` proxy needed. The server is a community project hosted by its author, not a commercial service, so treat it as best-effort.
