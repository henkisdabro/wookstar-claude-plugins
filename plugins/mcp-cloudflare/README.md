# mcp-cloudflare (retired)

Cloudflare publishes an official plugin for the same server, plus Workers and Wrangler skills.

```bash
claude plugin install cloudflare@claude-plugins-official
claude plugin uninstall mcp-cloudflare@wookstar-claude-plugins
```

This version contains nothing but a startup notice pointing here. It will be removed from the marketplace in a later release. See [MIGRATION.md](https://github.com/henkisdabro/wookstar-claude-plugins/blob/main/MIGRATION.md).
